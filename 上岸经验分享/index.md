## 如何投稿

1. **提交 Issue**：在仓库 Issues 页提出修改建议或补充内容
2. **提交 Pull Request**：Fork 本仓库，写好内容后提交 PR
3. **联系维护者**：不熟悉 GitHub 操作，可把内容发给维护者代为整理

## 投稿内容参考

- 个人备考经验（初试 / 复试均可）
- 方向选择与导师情况
- 避坑经验与教训
- 任何你认为对后来者有价值的信息

> 投稿格式不限，真实即可。哪怕只是一段话、一个 tips，也可能对别人产生巨大帮助。
